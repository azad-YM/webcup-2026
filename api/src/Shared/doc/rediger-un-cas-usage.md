## Format de référence

```text
En tant que <acteur>,
je veux <capacité>,
afin de <valeur métier>.
```

Chaque story prête au développement devra également préciser ses critères d'acceptation, règles associées, cas d'erreur, habilitations, données nécessaires et exigences de traçabilité. Les listes actuelles constituent un backlog de cadrage, pas des spécifications prêtes à implémenter.

Chaque règle, story ou cas d’usage est rédigé dans le dossier `doc` du BC ou SD propriétaire, puis référencé depuis les applications qui le présentent.
