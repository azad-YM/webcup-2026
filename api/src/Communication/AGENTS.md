# Communication

Lire [la documentation](doc/README.md). Publications, alertes et règles d’audience appartiennent à ce BC. L’autorisation est demandée à Administration par `CommunicationAccessPolicy`, le profil d’audience à Citizen par `AudienceProvider`. Aucune donnée sanitaire détaillée. Les notifications sont une vue filtrée des publications importantes et alertes actives ; le temps réel ne diffuse que leur identifiant.
